# Sitio de prueba: Centro de formación

Sitio de ejemplo de tres páginas, utilizado para practicar vínculos, rutas relativas y la publicación con GitHub Pages.

## Sitio publicado

https://brianchagas.github.io/sitio-de-prueba/

## Contenido

- `index.html`: página de inicio, con anclas a sus secciones y un enlace externo.
- `cursos.html`: listado de cursos, índice de la página y tabla de horarios.
- `paginas/contacto.html`: datos de contacto, con enlaces de correo y teléfono.
- `css/estilos.css`: hoja de estilos compartida por las tres páginas.
- `img/aula.svg`: imagen del sitio.

## Qué se practica

- Vínculos entre páginas con rutas relativas, incluida una página dentro de una subcarpeta (`../`).
- Anclas para ir a una sección de la misma página o de otra página.
- Etiquetas básicas de SEO: título y descripción propios en cada página.
- Publicación de un sitio estático con GitHub Pages.

## Tecnologías

HTML5 y CSS3, sin frameworks.
